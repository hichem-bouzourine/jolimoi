# Roman Numerals Converter

This is a small technical test project.  
It consists of:

- A **backend** in Node.js with Express that exposes an API to convert integers into Roman numerals.
- A **frontend** built with Vite + React that lets the user type a number between 0 and 100 and displays the Roman numeral result.

---

## Installation & Setup

### 1. Clone the repo

```bash
git clone https://github.com/hichem-bouzourine/jolimoi.git
cd jolimoi
```

### 2. Install dependencies

Make sure you have Node.js and npm installed.

#### backend

cd backend
npm install

#### frontend

cd ../frontend
npm install

### 3. Run the applications

cd backend
npm start
cd ../frontend
npm run dev

## 4. Access the application

Open your browser and go to [http://localhost:5173](http://localhost:5173) to access the frontend.
You will find a simple form to input a number between 0 and 100.
